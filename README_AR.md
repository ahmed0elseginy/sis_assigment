# نظام معلومات الطلاب - Student Information System (SIS)

## نظرة عامة / Overview

نظام معلومات الطلاب هو تطبيق شامل لإدارة العملية التعليمية في المؤسسات التعليمية. يوفر النظام وظائف متكاملة للطلاب والأساتذة والإدارة لإدارة جميع جوانب العملية التعليمية.

**Student Information System** is a comprehensive application for managing the educational process in educational institutions. The system provides integrated functions for students, professors, and administration to manage all aspects of the educational process.

---

## المميزات الرئيسية / Main Features

### 1. إدارة التسجيلات / Registration Management

#### أ) تسجيل الطلاب / Student Registration
- تسجيل طلاب جدد مع معلوماتهم الكاملة
- منع تكرار رقم الطالب (Student ID) - خاصية فريدة
- تخزين: الاسم، البريد الإلكتروني، الهاتف، القسم، المستوى الأكاديمي

#### ب) التسجيلات الأساسية / Basic Registrations
- **المستويات الأكاديمية**: السنة الأولى، الثانية، الثالثة، الرابعة
- **الكليات**: تسجيل الكليات المختلفة
- **الأقسام**: تسجيل الأقسام ضمن الكليات
- **المقررات**: تسجيل المقررات الدراسية مع رمز المقرر، الاسم، عدد الساعات المعتمدة
- **قاعات المحاضرات**: تسجيل القاعات مع سعة الاستيعاب
- **المختبرات**: تسجيل المختبرات مع سعة الاستيعاب
- **الأساتذة**: تسجيل بيانات الأساتذة والمدرسين

---

### 2. عمليات الإدارة / Management Operations

#### أ) تخصيص الطلاب / Student Assignments
- **تخصيص الطالب لمستوى أكاديمي**: تحديد سنة الدراسة للطالب
- **تخصيص الطالب لقسم**: ربط الطالب بقسم معين
- **تخصيص الطالب لمقرر**: إضافة الطالب لمقرر دراسي معين
- **تخصيص الطالب لمجموعة**: إضافة الطالب لمختبر أو مجموعة تمرين

---

### 3. نظام الدرجات / Grades System

#### أ) إدخال الدرجات / Grade Entry
- **الواجب الأول**: إدخال درجات الواجب الأول
- **الواجب الثاني**: إدخال درجات الواجب الثاني
- **أعمال المقرر (CW)**: إدخال درجات أعمال المقرر
- **الامتحان النهائي**: إدخال درجات الامتحان النهائي

#### ب) حساب المعدل التراكمي / GPA Calculation
- حساب المعدل التراكمي (GPA) للطالب تلقائياً
- يعتمد على نظام الدرجات 4.0
- يأخذ في الاعتبار عدد الساعات المعتمدة لكل مقرر

#### ج) كشف الدرجات / Transcript
- عرض كشف درجات شامل للطالب
- يظهر جميع المقررات مع درجات الواجبات والامتحان النهائي
- عرض منسق وسهل القراءة

---

### 4. الجداول الدراسية والحضور / Schedules & Attendance

#### أ) الجداول الدراسية / Lecture Schedules
- إنشاء جداول المحاضرات للمقررات
- تحديد: اليوم، الوقت، القاعة
- عرض الجدول الدراسي الكامل

#### ب) تتبع الحضور والغياب / Attendance Tracking
- تسجيل حضور وغياب الطلاب
- حالات الحضور: حاضر، غائب، متأخر، معذور
- عرض سجل الحضور لكل طالب
- عرض حضور الطلاب في مقرر معين في تاريخ محدد

---

## أدوار المستخدمين / User Roles

### 1. الطالب / Student
**الصلاحيات:**
- عرض الجداول الدراسية
- عرض الدرجات والنتائج
- عرض كشف الدرجات (Transcript)
- عرض سجل الحضور
- **لا يمكنه**: التسجيل أو التعديل أو إدخال البيانات

### 2. الأستاذ / Professor
**الصلاحيات:**
- إدخال الدرجات (الواجبات، أعمال المقرر، الامتحان النهائي)
- تسجيل الحضور والغياب
- عرض الجداول الدراسية
- عرض بيانات الطلاب في مقرراته
- **لا يمكنه**: التسجيل أو العمليات الإدارية

### 3. الإدارة / Administration
**الصلاحيات الكاملة:**
- جميع وظائف التسجيل
- جميع العمليات الإدارية
- إدارة الدرجات
- إدارة الجداول والحضور
- الوصول الكامل لجميع البيانات

## التثبيت والإعداد / Installation & Setup

### المتطلبات / Requirements
- **Qt Framework**: الإصدار 6.10.1 أو أحدث
- **Visual Studio**: 2022 مع Qt Tools
- **نظام التشغيل**: Windows 10/11

### خطوات التثبيت / Installation Steps

1. **فتح المشروع**
   ```
   فتح ملف sis_assigment.slnx في Visual Studio
   ```

2. **التحقق من إعدادات Qt**
   - التأكد من وجود Qt 6.10.1_msvc2022_64
   - التحقق من إعدادات Qt في Project Properties

3. **البناء / Build**
   ```
   Build → Rebuild Solution
   ```

4. **التشغيل / Run**
   ```
   Debug → Start Debugging (F5)
   ```

## استخدام النظام / Using the System

### أول مرة / First Time Setup

1. **عند فتح التطبيق لأول مرة:**
   - سيظهر رسالة تطلب تحميل بيانات تجريبية
   - اضغط "Yes" لتحميل البيانات العربية التجريبية
   - البيانات تشمل: طلاب، أساتذة، مقررات، درجات، جداول، حضور

2. **اختيار الدور / Role Selection:**
   - اختر دورك: طالب، أستاذ، أو إدارة
   - سيتم تخصيص الصلاحيات تلقائياً

### الاستخدام اليومي / Daily Usage

#### للطلاب / For Students:
1. اختر "Student" عند تسجيل الدخول
2. انتقل إلى تبويب "Schedules" لعرض الجدول
3. انتقل إلى تبويب "Grades" لعرض:
   - حساب المعدل التراكمي
   - كشف الدرجات
4. انتقل إلى تبويب "Attendance" لعرض سجل الحضور

#### للأساتذة / For Professors:
1. اختر "Professor" عند تسجيل الدخول
2. في تبويب "Grades":
   - أدخل درجات الواجب الأول والثاني
   - أدخل درجات أعمال المقرر
   - أدخل درجات الامتحان النهائي
3. في تبويب "Attendance":
   - اختر الطالب والمقرر والتاريخ
   - سجل حالة الحضور (حاضر/غائب/متأخر/معذور)

#### للإدارة / For Administration:
1. اختر "Administration" عند تسجيل الدخول
2. في تبويب "Registration":
   - سجل الطلاب الجدد
   - سجل المقررات والكليات والأقسام
   - سجل القاعات والمختبرات
   - سجل الأساتذة
3. في تبويب "Operations":
   - خصص الطلاب للمستويات الأكاديمية
   - خصص الطلاب للأقسام
   - سجل الطلاب في المقررات
   - خصص الطلاب للمختبرات ومجموعات التمرين
4. في تبويب "Schedules":
   - أنشئ الجداول الدراسية للمقررات
5. في تبويب "Grades" و "Attendance":
   - جميع الوظائف المتاحة

## نصائح للاستخدام / Usage Tips

### 1. تسجيل الطلاب الجدد / Registering New Students
- تأكد من استخدام رقم طالب فريد
- أدخل جميع الحقول المطلوبة (المميزة بعلامة *)
- تحقق من صحة البريد الإلكتروني

### 2. إدخال الدرجات / Entering Grades
- يجب تسجيل الطالب في المقرر أولاً
- يمكن إدخال درجات متعددة لنفس الطالب في نفس المقرر
- النظام يحسب المعدل التراكمي تلقائياً

### 3. الجداول الدراسية / Schedules
- يمكن إضافة محاضرات متعددة لنفس المقرر
- تأكد من اختيار قاعة مناسبة للسعة المطلوبة

### 4. الحضور / Attendance
- يمكن تسجيل الحضور لعدة طلاب في نفس الوقت
- استخدم الحالات: Present, Absent, Late, Excused

## استكشاف الأخطاء / Troubleshooting

### المشكلة: لا يمكن فتح الملف التنفيذي
**الحل:**
1. أغلق أي نافذة للتطبيق مفتوحة
2. في Task Manager: ابحث عن `sis_assigment.exe` وأغلقها
3. حاول البناء مرة أخرى

### المشكلة: البيانات لا تظهر
**الحل:**
1. تأكد من اختيار "Yes" عند تحميل البيانات التجريبية
2. تحقق من وجود مجلد `sis_data` في `AppData`
3. أعد تشغيل التطبيق

### المشكلة: خطأ في التسجيل - رقم الطالب مكرر
**الحل:**
- هذا طبيعي! النظام يمنع تكرار أرقام الطلاب
- استخدم رقم طالب جديد
